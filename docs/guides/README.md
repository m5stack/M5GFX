# Usage guides

Choose the task you want to perform. Each route connects the relevant API topic
to a complete example.

## Draw shapes or build a dashboard

Start with [drawing and colors](../api/drawing.md), then explore
[BarGraph](../../examples/Basic/BarGraph) or [AnalogMeter](../../examples/Basic/AnalogMeter).

## Place text and select a font

Use [text and fonts](../api/text.md). See [LvglFont](../../examples/Basic/LvglFont)
and [VlwFont](../../examples/Basic/VlwFont) for font examples.

## Display an image

Use [images](../api/images.md) and the [drawImageData](../../examples/Basic/drawImageData)
example, including its accompanying image data.

## Animate or redraw a region

Read [Sprites](../api/sprites.md) and [transactions and transfers](../api/transfers.md).
Explore [SpinTile](../../examples/Basic/SpinTile) and [ScrollGraph](../../examples/Basic/ScrollGraph).

## Change the display direction

Read [setRotation](../api/display.md#orientation-and-dimensions), use the
[device reference views](../device-orientation.md), and run
[DisplayRotation](../../examples/Basic/DisplayRotation) on a supported LCD.

## Read touch input

Read [touch input](../api/touch.md) and run [TouchTest](../../examples/Basic/TouchTest)
on a device with touch support.

## Use e-paper or an external display

Start with the [device guides](../devices/README.md), then read
[display control](../api/display.md) for the related API families.
