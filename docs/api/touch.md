# Touch input

Touch input requires a touch controller. Distinguish raw controller coordinates from coordinates converted for the display. The touch example shows both.

## Availability and reading

`touch()`, `getTouch()`, `getTouchRaw()`.

## Coordinate conversion

`convertRawXY()`.
