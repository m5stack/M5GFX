# Drawing and colors

Choose an outline or filled shape, then express its position in the current drawing surface coordinates.

## Pixels and lines

`drawPixel()`, `drawLine()`, `drawFastHLine()`, `drawFastVLine()`.

## Shapes

`drawRect()`, `fillRect()`, `drawRoundRect()`, `fillRoundRect()`, `drawCircle()`, `fillCircle()`, `drawEllipse()`, `fillEllipse()`, `drawTriangle()`, `fillTriangle()`.

## Surface and color

`fillScreen()`, `clear()`, `setColor()`, `color565()`, `color888()`.
