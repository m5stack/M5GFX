# Images

Choose a pixel-buffer API for decoded pixels or an image decoder for encoded data. File overloads require the appropriate filesystem integration; check the include order in the example.

## Pixel buffers

`pushImage()`, `setSwapBytes()`.

## Encoded image data

`drawJpg()`, `drawPng()`, `drawBmp()`.

## Files

`drawJpgFile()`, `drawPngFile()`, `drawBmpFile()`.

## Learn more

See [drawImageData](../../examples/Basic/drawImageData) for image data, file and URL examples.
