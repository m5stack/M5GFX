# Text and fonts

Use cursor-based output for sequential text and positioned strings for labels. Select a font that contains the characters your application needs.

## Font and appearance

`setFont()`, `setTextSize()`, `setTextColor()`.

## Position and alignment

`setCursor()`, `setTextDatum()`, `setTextPadding()`.

## Output and measurement

`print()`, `printf()`, `drawString()`, `textWidth()`, `fontHeight()`.

See [LvglFont](../../examples/Basic/LvglFont), [VlwFont](../../examples/Basic/VlwFont) and [LongTextScroll](../../examples/Basic/LongTextScroll).
