# Device orientation

The figures show the upright direction for each device at `setRotation(0)` since M5GFX 0.3.0.
Face the screen with the **TOP** edge pointing upward. In this position:

- **F** reads upright.
- **(0, 0)** is the top-left corner; **X** increases to the right and **Y** downward.
- The dimensions below each device give the screen width and height in pixels.

For circular screens, coordinates refer to the rectangle enclosing the visible circle.
Basic, M5GO and Gray share the Core figure.
